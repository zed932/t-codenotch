# Codenotch (корпоративная сборка)

Минимальная macOS-версия [Codenotch](LICENSE): чёрный notch у края экрана с кольцами лимитов корпоративного агента.

Из исходного проекта оставлен только UI. Удалены провайдеры, чтение чужих токенов и сессий, запуск CLI, локальные серверы, Phone Link, автообновление Sparkle, Windows-порт и публичная release-инфраструктура. Приложение собрано в App Sandbox без сетевых и файловых entitlements, поэтому macOS сама запрещает ему сеть и доступ к файлам вне своего контейнера.

Пока источник лимитов не подключён, notch показывает «Источник не подключён». Демонстрационные значения включаются в настройках и всегда помечены «ДЕМО».

## Сборка

Нужны Xcode и [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```sh
make test      # сборка и unit-тесты
make run       # Debug-сборка и запуск
make release   # Release-сборка в build/DerivedData
make verify    # проверка entitlements и отсутствия встроенных фреймворков
```

По умолчанию подпись ad-hoc; для распространения задайте корпоративную identity в `project.yml`.

## Устройство

- `Sources/Notch/` — окно, геометрия, форма и анимация notch.
- `Sources/Features/` — кольцо лимита и карточка при наведении.
- `Sources/Model/` — `UsageSnapshot` (нейтральные числа без аккаунтов и путей) и `UsageStore`.
- `Sources/Integration/` — протокол `UsageSource`, неактивный источник по умолчанию и демо-источник.
- `Sources/Settings/` — настройки внешнего вида и демо-режима.

## Подключение источника

Реализуйте `UsageSource.fetchSnapshot()` и верните его из `UsageSourceFactory`. Любой источник, которому нужна сеть или чтение файлов, потребует нового entitlement в `project.yml`, и это расширение прав нужно согласовать. Подробности в [плане очистки](docs/corporate-cleanup-plan.md).
